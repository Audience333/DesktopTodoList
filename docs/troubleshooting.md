# 故障排查

## 窗口不见了，或通知区域图标找不到

- 按 `Ctrl+Alt+T` 显示/隐藏窗口；如果你曾在设置中修改该组合键，以修改后的快捷键为准。
- 在 Windows 任务栏通知区域（system tray / notification area）中找到 DesktopTodoList 图标，双击显示窗口，或右键打开菜单并选择“显示窗口”。
- Windows 可能将图标收在通知区域的“显示隐藏的图标”菜单中。若刚重启过 Windows 资源管理器，等待几秒让图标重新出现；应用会尝试自动恢复托盘图标。
- 如果启动时提示无法注册通知区域图标，程序会停止启动，避免窗口收起后无法找回。重启应用或 Windows 后仍失败，请记录提示内容和 Windows 版本。

## 通知没有弹出

- 应用的提醒会先尝试 Windows 通知；不可用时会回退到通知区域气泡。因此先检查 DesktopTodoList 是否仍在运行，以及通知区域图标是否存在。
- 在 Windows“设置 → 系统 → 通知”中检查系统通知总开关和 DesktopTodoList 的通知权限；同时确认“专注助手/请勿打扰”没有隐藏通知。
- 检查任务是否设置了提醒时间、提醒是否启用，以及设置的提前时间。已完成任务不会作为待办提醒。
- 如果 Windows Toast 不可用，但托盘气泡仍无法显示，可重新启动应用，并确认系统任务栏通知区域没有被策略禁用。

## 快捷键无效或与其他程序冲突

- `Ctrl+Alt+T` 默认显示/隐藏窗口；`Ctrl+Alt+L` 默认切换鼠标交互状态。全局组合键可能已被其他程序占用（hotkey conflict）。
- 打开“设置”，给“显示/隐藏快捷键”或“交互恢复快捷键”换一个未占用的组合键，然后保存设置。
- 如果只有 `Ctrl+Alt+T` 注册失败，仍可通过通知区域菜单显示窗口。若 `Ctrl+Alt+L` 失效且窗口处于鼠标穿透状态，右键通知区域图标，选择“允许交互”。
- 多个程序同时启动时，先退出可能占用相同组合键的软件，再重新启动 DesktopTodoList。

## 登录 Windows 时没有自动启动

- 自动启动默认关闭。打开应用“设置”，勾选“登录 Windows 时自动启动”，然后点击“保存设置”（autostart is controlled in settings）。
- 在 Windows“设置 → 应用 → 启动”中确认 DesktopTodoList 未被关闭；也检查安全软件或组织策略是否禁止用户级启动项。
- 如果应用被移动或卸载后重装，重新打开应用并保存自动启动设置，使启动项指向新的程序位置。
- 自动启动失败不会影响手动从开始菜单或便携目录启动。便携版也可在应用设置中启用当前用户的自动启动。

## 数据没有显示或导入失败

- 确认当前登录的是保存数据时使用的 Windows 用户。安装版和便携版都读取 `%LOCALAPPDATA%\DesktopTodoList\data.json`。
- 导入只接受有效 JSON。重新从旧版导出文件；导入时选择合并或替换。替换前的应用数据会先备份在 `backups` 子目录。
- 不要手动编辑 `data.json`。若文件损坏，先退出应用并复制整个 `%LOCALAPPDATA%\DesktopTodoList` 文件夹，再联系维护者；自动备份位于其中的 `backups` 文件夹。

## 仍需帮助

反馈时请提供 DesktopTodoList 版本（可运行程序查看发行版本信息）、Windows 版本、问题发生步骤和完整错误提示。不要公开包含私人任务的 `data.json` 或备份；如需提供数据，请先确认并移除敏感内容。
