# DesktopTodoList 2.0.2

## 更新内容

- 修复“添加任务”输入区域点击后不能正常聚焦的问题；从标题编辑切换到新建任务时会先保存标题草稿。
- 改善不同显示缩放比例下的浮窗绘制尺寸，避免窗口内容被裁切。
- 快捷键注册失败时显示具体组合键和 Windows 错误码；鼠标穿透恢复快捷键不可用时保持可交互状态，避免无法找回窗口。
- 新增安装时创建桌面快捷方式的选项，默认不勾选。
- 登录 Windows 自动启动仍默认关闭，可在应用设置中主动开启；首次启动默认显示主窗口。
- 发布流程现在会准确区分已签名与未签名产物；只配置一项签名密钥仍会拒绝发布。

## 下载

- `DesktopTodoList-x64-Setup.exe`：Intel / AMD 64 位 Windows 安装版。
- `DesktopTodoList-arm64-Setup.exe`：Windows on ARM 原生安装版。
- `DesktopTodoList-x64-portable.zip` 与 `DesktopTodoList-arm64-portable.zip`：对应架构的便携版。
- `DesktopTodoList-x64.exe` 与 `DesktopTodoList-arm64.exe`：对应架构的主程序。
- `checksums.txt`：所有发布文件的 SHA-256 校验值及签名状态。

## 安全提示

**本版本未使用 Authenticode 签名。** 因本次发布未配置签名证书，`checksums.txt` 将标记 `Signature status: unsigned`。Windows 可能显示“未知发布者”或 SmartScreen 安全提示；请只从本项目 GitHub Releases 下载，并核对 SHA-256 校验值。不要将此版本误认为已验证发布者身份的签名版本。
